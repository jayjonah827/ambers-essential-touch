## User flow — canonical 4 paths

**Path A — Returning client rebooking**
FB/IG link → Home → Book → Select service → Pick time → Intake form → Confirm → SMS/email reminder → done

**Path B — Curious first-timer (mobile)**
Google search → Home → About → Reviews → Back to Home → Book → Confirm

**Path C — Product buyer (Phase 1: inquiry flow)**
IG post → Shop → Product detail → "Message to reserve" button → opens SMS or email with product pre-filled → Amber confirms + invoice via PayPal/Venmo

**Path C — Product buyer (Phase 2: Stripe on)**
IG post → Shop → Product detail → Add to cart → Checkout → Stripe → Confirmation email

**Path D — Donor / community supporter**
Flyer QR code → Donate → Read mission → Choose amount → Stripe/PayPal → Thank-you screen → Optional: "Would you like to know who your donation helps next?" → email capture → added to Skin Notes list

## Mobile vs desktop rules
- **Mobile first.** 72% of Amber's current inbound is mobile (FB + Google Maps). Build every page at 375px before touching 1440px.
- No horizontal scroll. No full-bleed video over text. Tap targets ≥ 44×44px.
- Single-column on mobile. Two-column on tablet+. Three-column only on desktop for product grid and service grid.
- Sticky bottom bar on mobile = `Book` (full width, amber fill). All other CTAs collapse into footer.

## URL + SEO conventions
- All URLs kebab-case, lowercase, no trailing slash.
- Title tag pattern: `{Page} · Amber's Essential Touch · Pinole, CA`
- H1 per page: unique, voice-matched (see 03_SPECIFICATION)
- Alt text: every photo of Amber = "Amber, licensed esthetician, Pinole CA"; product shots = `{product name} — {scent} — Amber's Essential Touch`
