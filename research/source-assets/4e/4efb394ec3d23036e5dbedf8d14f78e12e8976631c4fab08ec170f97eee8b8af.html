  2. Replace generated label copy. Establish one product nomenclature system, one language policy, one volume convention, and one typographic hierarchy across jar, serum, oil, and spray formats.
  3. Rebuild the mobile interface in Figma. Keep the dark bubble field, frosted panel, and quiet information rhythm. Replace generated text with final interface copy and component states.
  4. Create clean public campaign boards. Reconstruct the two synthesis boards using the selected final assets, vector wordmark, and authored copy.
  5. Separate archive layers. Keep reference boards internal; retain pyramid packaging and thymoquinone work as expansions; do not erase them or mistake them for locked decisions.
  6. Run publication review. Verify source rights for public reference images, replace scientific diagrams with verified diagrams, and review cosmetic effect claims before any commercial label or storefront use.
