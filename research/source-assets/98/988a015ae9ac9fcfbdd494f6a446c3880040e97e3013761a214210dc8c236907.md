# Amber Portrait Production System

This workspace preserves Amber's photographed presence through source-first production controls. It is not a face model, embedding, or training dataset, and no training claim should be made from these files.

## Source hierarchy

1. `reference/approved/amber-seated-authoritative.jpeg` is the sole edit target for the botanical mirror portrait. Its face, expression, body, pose, hands, clothing, jewelry, chair, and crop are authoritative.
2. `reference/approved/amber-spa-identity-support.jpeg` is supporting evidence for facial detail, natural skin texture, and loc character. It must never replace the edit target.
3. `reference/approved/amber-seated-edge-support.jpeg` is supporting evidence for silhouette and extraction edges only.
4. Generated images are outputs, never identity sources.

## Production flow

`approved photograph -> role manifest -> identity-lock prompt -> background-only edit -> human QA -> approved output`

Every new portrait run must:

- begin from an approved photograph, not a prior generated image;
- assign exactly one authoritative edit target;
- state every supporting image's limited role;
- lock identity, expression, skin, locs, body, hands, pose, clothing, and jewelry;
- make the smallest requested environmental change;
- preserve originals and write a new versioned output;
- pass `QA_CHECKLIST.md` before publication.
